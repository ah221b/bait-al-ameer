# BAIT AL AMEER — بيت الأمير

Corporate showcase website for **BAIT AL AMEER Bldg. Tools Tr. L.L.C** — a construction tools & marble accessories trading company in Sharjah, UAE.

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React Icons**
- Optimized for **Vercel** deployment

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Adding Product Images

Drop your product images into `public/images/`. See [`public/images/README.md`](./public/images/README.md) for the full list of expected filenames and recommended dimensions.

A company logo can be placed at `public/images/logo.png`.

## Deploying to Vercel

1. Push to a GitHub repository
2. Import the repo on [vercel.com](https://vercel.com)
3. Click **Deploy** — zero configuration needed

Or use the Vercel CLI:

```bash
npx vercel
```

## Features

- 🌐 **Bilingual** — Full Arabic (RTL) & English (LTR) with one-click toggle
- 📱 **Responsive** — Mobile-first design with hamburger nav
- 🏗️ **Professional** — Deep navy + accent orange industrial theme
- 📦 **Filterable Products** — Gallery with category filters
- 💬 **WhatsApp Integration** — Floating CTA + per-product inquiry links
- 🔍 **SEO Ready** — Metadata, Open Graph, semantic HTML
