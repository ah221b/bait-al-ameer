# Product & Media Assets Directory

Place your corporate and product images directly into this folder (`/public/images/`). The website automatically detects and displays them. If an image is missing, a clean industrial fallback placeholder is shown.

---

### 1. Brand & Background Assets
- `logo.png` — Company Logo (Recommended: transparent PNG, ~300×100 px or square ~120×120 px)
- `hero-bg.jpg` — Hero section industrial backdrop (Recommended: 1920×1080 px)
